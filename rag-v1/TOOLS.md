# Tools Used in RAG V1

## Python
Main programming language used to build the RAG system.

## Sentence Transformers
Converts text into numerical embeddings.

Model:
sentence-transformers/all-MiniLM-L6-v2

## NumPy
Used for numerical and vector operations, including cosine similarity.

## Transformers
Used to load and run the local AI language model that generates answers.

## PyTorch
Provides the underlying machine-learning computations needed to run the AI model.

## Hugging Face
Provides access to pretrained AI models that we can use in our project.
